# Milestone 2 browser-event contract matrix

`schemas/events/` is the canonical request-contract source. The event body is
strict and minimized; identity and persistence-only fields are server-derived.

| Canonical field                                     | Type and presence            | Limit                               | Privacy classification          | PostgreSQL mapping                              | TypeScript / Python                                                                         | Decision               |
| --------------------------------------------------- | ---------------------------- | ----------------------------------- | ------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------- | ---------------------- |
| `device_id`                                         | UUID, required batch field   | —                                   | Pseudonymous device identifier  | `browser_events.device_id`                      | `BrowserEventBatch.device_id` / `EventBatch.device_id`                                      | Keep at batch boundary |
| `session_id`                                        | UUID, required batch field   | —                                   | Pseudonymous session identifier | `browser_events.session_id`                     | `BrowserEventBatch.session_id` / `EventBatch.session_id`                                    | Keep at batch boundary |
| `client_event_id`                                   | string, required             | 1–128 chars                         | Client correlation identifier   | `browser_events.client_event_id`                | `BrowserEvent.clientEventId` / `BrowserEvent.client_event_id`                               | Keep                   |
| `sequence_number`                                   | integer, required            | >= 0                                | Ordering metadata               | `browser_events.sequence_number`                | `BrowserEvent.sequenceNumber` / `BrowserEvent.sequence_number`                              | Keep                   |
| `event_kind`                                        | enum, required               | 3 approved values                   | Event category                  | `browser_events.event_kind`                     | `BrowserEvent.eventKind` / `BrowserEvent.event_kind`                                        | Keep                   |
| `occurred_at`                                       | RFC 3339 date-time, required | —                                   | Event timing metadata           | `browser_events.occurred_at`                    | `BrowserEvent.occurredAt` / `BrowserEvent.occurred_at`                                      | Keep                   |
| `page_origin`                                       | HTTPS/HTTP origin, optional  | <=255 chars; no path/query/fragment | Minimized origin                | `browser_events.page_origin`                    | `BrowserEvent.pageOrigin` / `BrowserEvent.page_origin`                                      | Keep                   |
| `page_path_hash`                                    | SHA-256 hex string, optional | 64 chars                            | One-way path metadata           | `browser_events.page_path_hash`                 | `BrowserEvent.pagePathHash` / `BrowserEvent.page_path_hash`                                 | Keep                   |
| `page_title_redacted`                               | string, optional             | <=512 chars                         | Redacted browser text           | `browser_events.page_title_redacted`            | `BrowserEvent.pageTitleRedacted` / `BrowserEvent.page_title_redacted`                       | Keep                   |
| `accessibility_context_redacted`                    | string, optional             | <=12000 chars                       | Redacted browser text           | `browser_events.accessibility_context_redacted` | `BrowserEvent.accessibilityContextRedacted` / `BrowserEvent.accessibility_context_redacted` | Keep                   |
| `context_sha256`                                    | SHA-256 hex string, optional | 64 chars                            | Integrity metadata              | `browser_events.context_sha256`                 | `BrowserEvent.contextSha256` / `BrowserEvent.context_sha256`                                | Keep                   |
| `capture_policy_version`                            | string, required             | 1–64 chars                          | Capture-policy provenance       | `browser_events.capture_policy_version`         | `BrowserEvent.capturePolicyVersion` / `BrowserEvent.capture_policy_version`                 | Keep                   |
| `user_id`, `id`, `received_at`, `event_fingerprint` | server-derived               | —                                   | Identity/integrity metadata     | respective columns                              | Not request fields                                                                          | Derive server-side     |

Excluded fields include raw URLs, query strings, fragments, HTML, DOM, cookies,
clipboard/form values, credentials, OTPs, payment data, tokens, screenshot bytes,
and every unknown additional property.
